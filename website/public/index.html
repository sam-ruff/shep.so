Built in the open

A work in progress.
A clear direction.

Shep is still in development. Linux and Fastmail Inbox sync have been exercised; broader live-provider and platform verification is ongoing.

Mail currently uses text rendering, with external images blocked by default. The local mail cache is not encrypted. Gmail uses app passwords. Current limits include 25 MiB messages, 256 MiB raw-mail backups and a calendar window of 90 days back / 365 days ahead; edit recurring CalDAV series in your server's calendar UI.
