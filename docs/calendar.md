# Calendar

## Connect a calendar

Open **Preferences → Calendars**.

- **CalDAV:** choose **Add CalDAV calendar**, enter your server URL, username and app password, then select **Find calendars**. Choose the calendars you want to add.
- **Google Calendar:** follow [Google setup](backups.md#connect-google-optional), then sync your calendars.

## Plan your day

The Calendar tab shows a month grid and agenda. Double-click a day to create an all-day event, or use the new-event button for a timed event. Open an existing event to edit or delete it.

For an all-day event, the last date you enter is included. Read-only calendars remain available to view.

## Keep in mind

Sync covers the previous **90 days** and next **365 days**. Edit recurring CalDAV series in your server's calendar UI. If an event changed elsewhere, sync before trying your edit again.

Removing a calendar in Preferences removes its local cache; server events stay intact.
